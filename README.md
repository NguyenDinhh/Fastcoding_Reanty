# Reanty - Real Estate Website

A modern, responsive real estate website built with pure HTML5 and CSS3.

## 🌟 Features

- **100% Pure HTML & CSS** - No JavaScript dependencies
- **Fully Responsive** - Works on desktop, tablet, and mobile
- **Interactive Hover Effects** - Smooth transitions and animations
- **Google Maps Integration** - Embedded map in contact section
